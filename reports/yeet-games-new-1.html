games.js and sitemap.xml: game list check

Task YG-621. Branch task-1352 at commit 67c90b9. Checked files: games.js, sitemap.xml, scripts/generate-sitemap.py.

Summary

The sitemap and the catalog agree on the 13 game pages this repo serves. No page is in one list and missing from the other.

The sitemap has no broken URLs. All 18 sitemap URLs return HTTP 200 live.

The sitemap leaves out most catalog games. games.js has 381 entries. Of these, 329 point to paths that git does not track. The sitemap skips them by design. Many of these paths still return pages live.

One catalog link does not match its repo file. Backrooms links to /Games/backrooms. The tracked file is games/backrooms.html.

Findings

  1. Match. The 13 game pages in the sitemap are the same 13 HTML pages that games.js links inside this repo. See evidence section 4.
  2. Match. Every sitemap URL resolves to a tracked file. The live check returns 200 for all 18.
  3. Gap. 229 catalog paths return live HTML pages. The git tree does not track them, so the generator skips them. These are the largest difference. Examples: /Games10/geodash/index.html, /Games/paperio2/index.html, /slope/, /home/webb/.
  4. Gap. 41 catalog paths return 404 live. These are dead links in games.js. The sitemap does not list them, so the sitemap is not the cause. See the list in the evidence section.
  5. Gap. Backrooms: games.js links /Games/backrooms (capital G). The tracked page is games/backrooms.html (lowercase). The sitemap lists neither path. Live, /games/backrooms.html returns 200.
  6. Expected. 58 untracked catalog paths are live .swf files. The generator skips non-HTML files by design. Separately, 8 tracked .swf entries exist in the repo, and they are also skipped.
  7. Expected. 30 catalog entries point to other hosts. The sitemap does not list other hosts by design.

Method

  1. Read games.js and listed every url: value (381).
  2. Unwrapped loader links such as games/game.html?game=. Then mapped each path to a tracked file with the same rules as scripts/generate-sitemap.py, but written again from scratch.
  3. Ran scripts/generate-sitemap.py --check. It passed.
  4. Checked each sitemap URL and each untracked path with curl GET. No secret values were read or printed.

Limit: the worktree is a clean copy of origin/master. The check compares git-tracked files. It did not read the main checkout, so untracked files there are not included.
